Sesión activa

Ingresar al editor

Usá una clave de acceso de GitHub limitada únicamente a este sitio. La clave se mantiene en memoria durante esta sesión y se borra al cerrar o recargar la página.

La clave necesita permiso de lectura y escritura sobre el contenido del repositorio funciones-EJI.

Cómo crear la clave por primera vez
  1. Abrí GitHub · Nueva clave específica.
  2. Elegí solo el repositorio funciones-EJI.
  3. En permisos del repositorio, activá Contents: Read and write.
  4. Elegí una fecha de vencimiento breve, generá la clave y guardala en tu administrador de contraseñas.
